# Radio-T / текст

Переносимый генератор статического архива подкаста «Радио-Т»: расшифровки,
таймкоды, оглавление тем, аудиоплеер и краткие резюме. Без привязки к домену.
Python 3, стандартная библиотека; страницы работают без серверного приложения.

1. Скопировать `.env.example` в `.env`, вписать `OPENROUTER_API_KEY` (права 0600).
2. `python3 pipeline.py prepare` — бесплатно получить последний выпуск и нарезать аудио.
3. `python3 pipeline.py process` — распознать, сделать резюме и собрать `dist/`.
4. `python3 pipeline.py build` — пересобрать HTML без API и оплаты.

`--episode NUMBER` выбирает выпуск из последних 30 записей API.
`python3 pipeline.py latest` проверяет новый выпуск; готовый повторно не оплачивает.
Модели: Whisper Large V3 Turbo и GPT-6 Luna через OpenRouter. Лимит $0.15 на выпуск.
Публиковать только содержимое `dist/`; оно работает в любом пути сайта.
Ключи, аудио, ответы API и сборки исключены из Git. Подробности — `ARCHITECTURE.md`.
