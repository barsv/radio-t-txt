# Radio-T / текст

Здесь исходники переносимого генератора архива подкаста: загрузка выпусков,
расшифровки, резюме, таймкоды и статические страницы.

Перед изменениями прочитать `README.md` и `ARCHITECTURE.md`.
Сохранять переносимость: ссылки между страницами должны быть относительными,
а код и шаблоны не должны зависеть от конкретного домена, сервера или
локальных путей. Конфигурация хостинга находится за рамками этого проекта.

Для проверки страниц использовать `python3 pipeline.py build` с готовыми
материалами. Эта команда пересобирает сайт без вызовов внешнего API и оплаты.

Ключи, .env, аудио и ответы API не выводить в чат и не добавлять в Git.
Обработку с внешним API и расходами запускать в рамках явно поставленной
задачи; для проверки интерфейса использовать готовые материалы и сборку
без повторного платного распознавания. При параллельной работе проверять
изменения других чатов, не затирать их; длительные работы кратко описывать
в документации проекта. При изменении поведения обновлять `README.md`
и `ARCHITECTURE.md` по необходимости.
