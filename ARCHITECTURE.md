# Как устроено

`pipeline.py` получает метаданные и официальные границы тем через API Радио-Т.
MP3 нарезается по кадрам без перекодирования: до пяти минут с перекрытием около
трёх секунд. Whisper возвращает текст и время каждого слова (`verbose_json`).
Из относительного времени получается время в выпуске; перекрытия делятся
посередине. Слова группируются в абзацы около 20–30 секунд и по официальным темам.
Секундная точность — оценка модели, особенно при одновременной речи и паузах.

Luna получает текст тем и возвращает JSON с общим обзором, резюме и тезисами.
Она не управляет файлами, не получает API-ключ и не вызывает другие инструменты.
`render_site.py` собирает из этих данных HTML, TXT, VTT и JSON. Шаблон, стили и
плеер не содержат адреса владельца: ссылки между страницами относительные.

## Повторные запуски и расходы

`state/<номер>/` хранит исходные данные, план нарезки, каждый ответ и стоимость.
Готовые ответы используются повторно. Запросы не повторяются автоматически,
если исход предыдущего запроса неизвестен: сначала нужно проверить файл
`*.attempt.json`. После проверки неудачную попытку можно архивировать вручную.
Перед запросами проверяются текущие тарифы и оставшийся бюджет. Лимит — $0.15
на выпуск; фактический итог в `complete.json`. HTML собирается во временной
директории и заменяет `dist/` только после успешного построения всех страниц.

## Публикация

Содержимое `dist/` можно положить в корень или подпапку любого статического
хостинга. Настройки домена, TLS, Nginx и расписания относятся к отдельному
проекту размещения. На странице используется оригинальное аудио с CDN Радио-Т.
Исходный подкаст и материалы принадлежат их авторам; LICENSE относится к коду.

`prepare_sample.py`, `transcribe_sample.py`, `transcribe_full.py` сохранены как
первые эксперименты с выпуском 1035; основной интерфейс — `pipeline.py`.
